# SEO Ops XAMPP Deploy

Copy toàn bộ nội dung thư mục này vào:

C:\xampp\htdocs\phaohoashop\seo-ops

Sau đó mở Apache trong XAMPP và truy cập:

https://phaohoa.shop/seo-ops

hoặc local:

http://127.0.0.1/seo-ops

API dữ liệu chung:

/seo-ops/api/data
/seo-ops/api/health

Database chung:

C:\xampp\htdocs\phaohoashop\seo-ops\db\seo-ops-data.json

Không cần Node.js.
